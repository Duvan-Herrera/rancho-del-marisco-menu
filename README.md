# rancho-del-marisco-menu

Menú digital responsive listo para GitHub Pages.

## Publicación

1. Cree un repositorio público de GitHub con el nombre rancho-del-marisco-menu.
2. Ejecute desde esta carpeta:

   git init
   git branch -M main
   git add .
   git commit -m "Publicar menú digital"
   git remote add origin https://github.com/TU_USUARIO/rancho-del-marisco-menu.git
   git push -u origin main

3. En Settings → Pages, seleccione GitHub Actions.
4. El enlace quedará como https://TU_USUARIO.github.io/rancho-del-marisco-menu/
